🌙 Pip — The Midnight Dream Engineer

> *“I build the dreams you fall asleep inside.”*

Welcome to **Pip's Midnight Nursery**, a tiny corner of the internet where dreams glow, lullabies come alive, and a sleepy little skull baby makes bedtime magical.

Pip is not a scary skeleton. Pip is a curious, sleepy, slightly clumsy **Junior Dream Engineer** who designs dreams for the little ghosts and creatures of the Midnight Nursery.

This project is my creative interpretation of Pip for the **Baby's First Website hackathon**.

## ✨ The Idea

Everyone starts with the same baby. What makes each project different is the creativity, personality, storytelling, animation, and frontend experience built around that character.

My vision is to transform Pip's portfolio into an interactive midnight dream world — a website that feels like entering a storybook just before falling asleep.

## 🎨 Design Vision

The website aims to create a distinctive visual identity inspired by a peaceful midnight nursery.

- **Atmosphere:** A dreamy night sky filled with stars and soft clouds.
- **Colors:** Midnight blue, lavender, soft pink, cream, and warm golden light.
- **Character design:** Preserve Pip's official skull-baby identity while developing an original visual style.
- **Typography:** Friendly, readable fonts with playful headings.
- **Motion:** Gentle floating clouds, twinkling stars, glowing lanterns, and smooth transitions.
- **Storytelling:** Present Pip as a little character with a job, a home, and a mission.

## 💻 Run Locally

Make sure Node.js and npm are installed.

**1. Clone the repository**

```bash
git clone https://github.com/chmythresh/haX-Baby.git
```

**2. Open the project folder**

```bash
cd haX-Baby
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the website.
